# 🌤️ Challenge Blip - Frontend Gateway

Este é o frontend do desafio técnico desenvolvido para a Blip. A aplicação consiste em uma interface React que consome uma API customizada (Gateway), permitindo a consulta de dados meteorológicos de qualquer cidade.

## 🚀 Link do Projeto
O deploy oficial da aplicação pode ser acessado aqui:
👉 **[Acessar App na Vercel](https://challenge-blip-frontend-gateway.vercel.app)**

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com foco em performance e tipagem estática:

- **React**: Biblioteca base para a construção da UI.
- **TypeScript**: Utilizado para garantir a integridade dos dados e facilitar a manutenção.
- **Vite**: Ferramenta de build de última geração para um desenvolvimento rápido.
- **CSS**: Estilização da interface.
- **Vercel**: Hospedagem e pipeline de CI/CD.

---

## ✨ Funcionalidades

- **Consulta de Clima**: Integração com o serviço de meteorologia através de um backend próprio.
- **Segurança via Gateway**: As requisições são autenticadas por meio de uma API Key via headers.
- **Tratamento de Erros**: Feedback visual para o usuário em caso de falhas na busca ou problemas de conexão.
